# Interactive Sales Dashboard in Excel 📊

This project presents the **Chitra Collections Annual Report 2024** through an interactive Excel dashboard using **Pivot Tables**, **Charts**, and **Slicers**. It provides key business insights for smarter, data-driven decisions.

---

## 🔍 Key Insights

- 📈 **Sales & Orders**: Tracks monthly trends and peak periods.  
- 🚚 **Order Status**: Visualizes completed, refunded, and cancelled orders.  
- 🗺 **Top States**: Maharashtra, Karnataka, and UP lead in revenue (~35%).  
- 👥 **Customer Demographics**: Adults (~50%) and women (~65%) dominate purchases.  
- 🛍 **Sales Platforms**: Amazon, Flipkart & Myntra account for ~80% of sales.  

---

## 🎯 Features

- 6 Pivot Charts for sales, orders, regions, demographics, and platforms  
- 3 Slicers: **Month**, **Category**, **Channel** for dynamic filtering  
- Clear visuals for quick and informed decision-making
